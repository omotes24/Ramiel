# BURST:最近傍で内容と向きを測る拡散モデルの分布外検知

26f WIP 中間発表の論文(TeX と PDF)と、実験のコードです。

## 手法

学習済みの拡散モデルのノイズ除去器を凍結したまま、テスト画像を 1 回だけ、途中のブロック X まで通します(ノイズの大きさ 0.01)。勾配で学習するものも、追加のネットワークも、ラベルも、分布外の画像も使いません。

1. 1 回の順伝播から 2 つの特徴を読みます。$`f`$ は、ブロック U の出力の、チャネルごとの平均と標準偏差を並べて長さ 1 にしたベクトル。$`z`$ は、入力側から X までの各ブロックの振幅 $`a_h`$ を、train 画像での平均と標準偏差でそろえて並べたものです($`C_h`$ はブロック $`h`$ のチャネルの数、$`\mu_c`$ はチャネル $`c`$ の平均)。

```math
a_h(x)=\frac{1}{C_h}\sum_{c=1}^{C_h}\log\max_{i,j}\left|h_{c,i,j}-\mu_c\right|
```

2. train 画像 $`N`$ 枚を、8 通りの向き(4 つの回転と、左右反転してからの 4 つの回転)で同じように通します。そのままの $`N`$ 個をバンク $`u`$、向きを変えた $`7N`$ 個をバンク $`o`$ とします。

3. 特徴 $`g\in\{f,z\}`$ ごとに、$`u`$ の $`R`$ 番目に近い要素までの距離 $`r^{u}_{R}`$ と、$`o`$ の $`7R`$ 番目に近い要素までの距離 $`r^{o}_{R}`$ から

```math
J_g(x)=d_g\min_{R}\left\{-2\log r^{u}_{R}(x)+\log r^{o}_{R}(x)-m_R\right\}
```

```math
s(x)=J_f(x)+J_z(x)
```

を求めます。$`-2\log r^{u}_{R}+\log r^{o}_{R}`$ は、最近傍による密度の推定 $`\log p_u`$ と、向きの比 $`\log(p_u/p_o)`$ の和です。$`R\in\{1,2,5,10,20,50,100,200,500,1000\}`$、$`m_R`$ は train 画像 5,000 枚での平均(自分自身とその写しを除く)、$`d_g`$ は train 画像から求める次元です。

ブロック U は、train 画像と、その向きを変えた写しを、最近傍の距離で最もよく見分けるブロックです(train 画像だけで選ぶ)。X は、U の 2 倍の解像度をもつデコーダのブロックのうち最後のものです。

## 結果(test 画像、ノイズの種 3 つの平均、自然画像の分布外集合に対する AUROC、%)

| 分布内 | CIFAR-10 | SVHN | CelebA | ImageNet-64 | FashionMNIST | 5 つの平均 |
|---|---|---|---|---|---|---|
| BURST | 96.2 | 98.6 | 100.0 | 84.5 | 100.0 | **95.9**(95% 信頼区間 95.6〜96.1) |
| 同じ拡散モデルを用いる 10 手法のうち、列ごとの最良 | 85.4 | 99.8 | 99.8 | 65.5 | 99.8 | 88.0 |

- 計算時間は、順伝播 1 回の 0.54 倍(分布内ごとに 0.45〜0.64)。
- 上下反転した分布内の画像は 86.8、左右反転は 61.0(弱点)。
- CFS の論文の評価手順(12 組)では、平均 98.2、分布内ごとの最悪の平均 96.2。
- 256×256 のモデル(ADM。ノイズの種 0)では、LSUN の寝室で 81.5、ImageNet で 85.0 にとどまります。向きの比が高めるのは上下反転の検知だけで(87.1 → 98.4、56.3 → 69.0)、自然画像の分布外集合には効いていません(論文の補足 A.6)。

表、各部分の寄与、組ごとの値は `paper/main.pdf` にあります。test 画像は、この手法より前の構成の評価にも使ってきた画像です(論文に記載)。

## 中身

| フォルダ | 内容 |

| `paper/` | 論文のソース(pLaTeX、MIRU 2025 のクラス)と PDF、数値と表の生成スクリプト `gen/mk.py`、その元データ `data/` |

## 作り方

    cd paper && python3 gen/mk.py && python3 gen/mk_schem.py && latexmk -r latexmkrc main.tex

GPU 側のコードを動かすには、データセットの配列、モデルの重み、外部のコード(NVlabs の EDM / EDM2、improved-diffusion、guided-diffusion)が別に要ります(`code/README.md`)。
